marble run is a fully 3d printed modular marble run set. you design the tracks yourself in onshape, print them and watch how the marble rolls.

# What is 'marble run'?


marble run is a modular marble race set designed from scratch. you build a base grid, and then custom track blocks that click together to create endless tracks! you can build straight runs, curves, drops, loops, and special feature tiles like vortexes, wiggly tracks, and drop holes.

# What it features


Modular 40mm grid system with interlocking pillar blocks and bases

Designed for standard 16mm marbles

13 unique component parts for custom track layouts

Smooth track transitions, drop features, and catch basins

# Why?


this project was designed to create a fun, reconfigurable, and expandable 3D printable modular marble run system!

# Status


the design library is done, featuring 13 unique modular components including bases, pillar blocks, ramps, straights, 90 degree turns, bridges, y splits, wiggly tracks, drop backs, drop holes, vortex bowls, catch basins, and marbles.

# Printing


marble run is designed so that the tracks use the slicer generated supports (thin tree) as the supports for the track, therefore serving 2 purposes. before printing, check that the supports are not getting generated in the middle of the tracks where the marble rolls.
